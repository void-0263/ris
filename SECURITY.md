| Version | Supported          |

| < 1.0   | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability in RIZ Learning Hub, please report it responsibly.

### How to Report

**Email:** rizlearning0263@gmail.com  
**Subject:** `[SECURITY] RIZ Learning Hub - Vulnerability Report`

**Please include:**
- Description of the vulnerability
- Steps to reproduce the issue
- Potential impact
- Your contact information

### Response Time

- **24-48 hours:** We'll acknowledge your report
- **7-14 days:** We'll provide an update on the fix
- **Ongoing:** We'll keep you informed throughout the process

---

## Guidelines

### Please DO:
✅ Report vulnerabilities privately via email  
✅ Give us reasonable time to fix the issue  
✅ Provide detailed information to help us understand the problem  

### Please DO NOT:
❌ Publicly disclose the issue before we've fixed it  
❌ Access or modify other users' data  
❌ Test on production systems without permission  

---

## Our Security Practices

- ✅ Firebase Authentication for secure user accounts
- ✅ Firestore Security Rules to protect user data
- ✅ HTTPS encryption for all communications
- ✅ Regular security updates and patches
- ✅ Minimal data collection policy
